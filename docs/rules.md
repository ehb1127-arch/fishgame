# 게임 규칙

Magic 계열의 기본 뼈대(마나, 스택, 우선권, 전투) 위에 이 게임만의 규칙
네 가지가 올라간다: **수심대**, **조류**, **난파선**, **시계**.

---

## 1. 승리 조건

상대 팀의 모든 플레이어가 패배하면 승리한다. 플레이어는 다음 중 하나로 패배한다.

- 생명점이 0 이하가 된다
- 빈 서고에서 카드를 뽑으려 한다
- 조난(Castaway) 모드에서 자기 시계를 다 쓴다

---

## 2. 턴 구조

```
시작단계 (언탭 → 유지단 → 뽑기)
전투전 본단계
전투 (시작 → 공격자 선언 → 방어자 선언 → 전투피해 → 종료)
전투후 본단계
종료단계 (종료단 → 정리단)
```

언탭단과 정리단에는 우선권이 없다. 그 외 모든 단계에서 양쪽이 우선권을 받고,
모두가 연속으로 넘기면 스택 맨 위가 해결되거나 다음 단계로 넘어간다.

**선공 플레이어는 첫 턴에 카드를 뽑지 않는다.**

---

## 3. 수심대 (Depth Bands) — 핵심 규칙

전장은 세 층으로 나뉜다.

```
수면 Surface
중층 Midwater
심해 Abyss
```

- 모든 생물은 카드에 인쇄된 **출현 수심**으로 전장에 들어온다
- **방어는 같은 수심대에서만 가능하다.** 공격자가 있는 층에 방어자가 없으면
  그 공격은 막히지 않는다
- **양서(Amphibious)** 를 가진 생물은 인접한 한 층까지 방어할 수 있다
- 자기 턴 본단계에 **생물 하나만** 한 층 이동할 수 있다 (소서리 타이밍)
- **잠행(Diver)** 은 이 제한을 무시하고 두 층까지 이동한다
- **정박(Anchored)** 은 이동할 수 없다
- 카드 효과로는 제한 없이 강제 이동시킬 수 있다 (예: 해일, 크라켄의 손아귀)

이 규칙이 비행/도달을 대체한다. 회피는 키워드가 아니라 **위치**의 문제다.

---

## 4. 조류 (Tide)

조류는 **밀물(High)** 과 **썰물(Low)** 을 오간다.

- 한 라운드(양쪽이 한 턴씩)마다 전환된다. 턴 1-2는 밀물, 3-4는 썰물, 5-6은 밀물...
- **밀물**: 수면의 생물이 +1/+0
- **썰물**: 심해의 생물이 +1/+0
- 중층은 항상 중립이다

양쪽에 동일하게 적용되고 주기가 예측 가능하므로, 몇 턴 뒤를 보고 미리
층을 옮겨두는 플레이가 성립한다.

---

## 5. 난파선 (The Wreck)

**양 플레이어의 무덤은 하나의 난파선 더미로 합쳐진다.**

- 죽은 카드는 소유자와 무관하게 난파선에 쌓인다
- **인양 N (Salvage N)**: 추가 비용으로 난파선에서 카드 N장을 추방한다
- 난파선에서 카드를 회수하는 효과는 **상대가 잃은 카드도 가져올 수 있다**

따라서 상대의 생물을 제거하는 것은 상대에게 연료를 주는 일이기도 하다.

---

## 6. 키워드

| 키워드 | 효과 |
|---|---|
| 격류 Riptide | 전투피해를 먼저 입힌다 |
| 소용돌이 Maelstrom | 전투피해를 두 번 입힌다 |
| 돌파 Breach | 방어자를 넘긴 초과 피해가 플레이어에게 간다 |
| 무리 Schooling | 생물 한 마리만으로는 막을 수 없다 |
| 먹물 Ink | 이 생물을 막은 생물들은 피해를 입히지 못한다 |
| 유인 Lure | 막을 수 있다면 반드시 막아야 한다 |
| 방파제 Breakwater | 공격할 수 없다 |
| 맹독 Venomous | 이 생물이 입힌 모든 피해는 치명적이다 |
| 흡혈 Siphon | 입힌 피해만큼 조종자가 생명을 얻는다 |
| 불면 Sleepless | 공격해도 탭되지 않는다 |
| 급류 Surging | 전장에 들어온 턴에 공격할 수 있다 |
| 미끄러움 Slippery | 상대는 목표로 정할 수 없다 |
| 불침 Unsinkable | 파괴되지 않는다 |
| 탈피 Molt | 턴에 한 번 치명상을 무효화한다 |
| 양서 Amphibious | 인접 수심대도 방어할 수 있다 |
| 잠행 Diver | 이동 제한을 무시하고 두 층까지 이동한다 |
| 정박 Anchored | 수심을 바꿀 수 없다 |
| 수압 Pressure | 심해에서 +2/+2, 수면에서 -1/-1 |
| 군체 Swarm | 같은 층의 다른 아군 생물 수만큼 +1/+0 |
| 광란 Frenzy | 이번 턴에 발동한 주문 수만큼 +1/+1 |

## 7. 영웅 (Champion)

영웅은 전장에 머무는 퍼머넌트로, **수심 인장(Fathom)** 카운터를 쓴다.

- 전장에 들어올 때 인쇄된 수만큼 인장을 갖는다
- **턴에 한 번**, 소서리 타이밍에 능력 하나를 쓴다. `[+1]`은 인장을 더하고
  `[-2]`는 인장을 소모한다
- 영웅이 받는 피해는 **인장을 대신 제거한다**
- 인장이 0이 되면 난파선으로 간다
- 같은 영웅은 전장에 하나만 존재할 수 있다
- 생물은 플레이어 대신 영웅을 공격 대상으로 지정할 수 있다

## 8. 시계

| 모드 | 턴 제한 | 초과 시 |
|---|---|---|
| 표준 Standard | 90초 | 턴 강제 종료 |
| 속도전 Blitz | 20초 | 턴 강제 종료 |
| 격류전 Riptide | 10초 | 턴 종료 + 생명 2 손실 |
| 조난 Castaway | 총 5분 (체스 시계) | 시간 소진 시 패배 |

카드로 제한 시간을 바꿀 수 있다. **압박수심**은 상대를 8초로 묶고,
**정적의 심해**는 자기 시간을 두 배로 늘린다. 이런 지속 효과는 해당 퍼머넌트가
전장을 떠나면 즉시 사라진다.

엔진 자체는 시간을 재지 않는다. UI가 재고, 시간이 다 되면 엔진에 알린다.
덕분에 규칙은 완전히 결정론적이고 헤드리스 테스트가 가능하다.

---

## 9. 상태기반 처리

우선권을 받기 직전마다 아래를 반복 확인한다.

- 생명 0 이하 → 패배
- 빈 서고에서 뽑기 시도 → 패배
- 방어력 0 이하인 생물 → 난파선 (불침도 소용없다)
- 치명상을 입은 생물 → 난파선 (**탈피**가 있으면 턴에 한 번 버틴다)
- 인장이 없는 영웅 → 난파선
- 같은 유니크/영웅이 둘 → 하나만 남는다

---

## 10. 다인전

- 플레이어는 **좌석 순서**와 **팀**을 가진다
- 우선권은 좌석 순서대로 돈다
- 공격자는 **어느 상대를 공격할지 지정**한다. 같은 팀은 공격할 수 없다
- 공격받은 플레이어가 각자 순서대로 방어를 선언한다
- **팀 단위로 승패가 결정된다**

2v2 협동과 1v1v1 난전이 같은 엔진에서 돌아간다.

---

## 실제 Magic과 다른 점 (의도한 단순화)

- 지속 효과 레이어는 두 가지(파워/방어력, 키워드 부여)만 구현한다
- 마나 지불은 자동이다. 어떤 대지를 탭할지 플레이어가 고르지 않는다
- 유발 능력의 목표는 자동 선택된다
- 오라, 장착, 변신은 아직 없다
